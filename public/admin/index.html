How to add products and preview changes

Add a product: Open Products → New. Add a name, product photo, short description and optional bullet points. Set the display order, supply type and enquiry category. Enable “Show in homepage grid” or “Show in full range list”, then Save. Products automatically follow the website’s existing design.

Local editing: In the editor, choose “Work with Local Repository” and select Arte-Website/4-Website-Code. Allow access when your browser asks. Save changes, then select Client website to preview them. Switch back to continue editing; your editor stays open. Use Chrome or Edge for local folder access.
