How to add products and preview changes

Add a product: Choose Add product. Add a name, product photo, short description and optional bullet points. Set the display order, supply type and enquiry category. Enable “Show in homepage grid” or “Show in full range list”, then Save. Products automatically follow the website’s existing design.

Sign in with your admin credentials. Save changes, then select Client website to preview them. Online changes publish after Vercel finishes deploying.
